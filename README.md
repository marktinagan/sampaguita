Tinagan Mark Iñego Distance Program.
A simple Python script that computes the distance between two points.
To run the program, execute “Tinagan-MarkInego-DistanceProgram.py” in your terminal, which will prompt you to enter the coordinates for x1, y1, x2, and y2 to calculate and print the distance between the two points.
The program requires four numerical values representing two coordinate points: enter the first point’s coordinates as x1 and y1, follow by the second point’s coordinates as x2 and y2.
After taking the four coordinate values, the script computes the result using the distance formula and print the calculated distance.
